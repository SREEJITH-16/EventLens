## 🎟️ What is EventLens?

**EventLens** is a modern event discovery hub designed to bring **IEEE Computer Society events at SRM IST Vadapalani** into one beautiful, easy-to-use platform.

Instead of searching through scattered announcements, EventLens gives students and members a centralized place to:

> 🔎 **Discover** → 🗂️ **Explore** → 📅 **Participate** → 🚀 **Connect**

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/SREEJITH-16/EventLens.git
```

Move into the project:

```bash
cd EventLens
```

Open:

```text
project 2/index.html
```

You can simply open the HTML file in your browser.

No complicated installation or build process is required.
